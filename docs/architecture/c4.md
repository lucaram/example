Rendered by GitHub. A plain flowchart is used because Mermaid's C4 syntax is still experimental.

## The closed quality loop (pillars 1 to 5)

```mermaid
flowchart LR
  ctx[Versioned context<br/>docs/, AGENTS.md] --> gen[AI generates<br/>tests and summaries]
  gen --> ev[Evals in CI<br/>deterministic then judge]
  ev --> gate[Release gate<br/>promote / hold / human review]
  gate --> prod[Production signals<br/>feedback, logs]
  prod --> fb[Flag becomes a candidate<br/>golden case]
  fb --> ctx
  trace[Traceability at every step:<br/>commit, model, prompt, eval, decision] -.-> ev
```
